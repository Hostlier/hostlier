# Go 1.27.3 and package infrastructure verification

Go 1.27.3 is the latest stable Go release on 2026-11-04. Hostlier and the active sibling `hostlier-packages` repository now require Go 1.27.3 in their Go modules. Hostlier's CLI and controller workflows, release scripts, Collector scripts, and digest-pinned Collector builder image use that version. The four Hostlier-owned Minion artifacts in the package catalog were rebuilt with Go 1.27.3 and their catalog SHA256 values were verified.

| Package | Shared package contract | Distribution status | Verification |
| --- | --- | --- | --- |
| Aiven | Publishes v1 `describe` metadata and uses `packagekit.Serve`. `hostlier package add aiven` works after local installation. | Listed in the default Git catalog, whose release-asset URLs still point to previously published binaries. | Standalone provider tests, a built `describe` response, core package-runner discovery, and a CLI install/add smoke test passed. Cloud provisioning was not exercised. |
| Terraform | Uses `iac.New` and typed `packagekit.Define` for plan, apply, inspect, and reconcile. | Listed in the default Git catalog; `describe` and execution require an administrator-installed pinned native bundle catalog. Published release-asset URLs are unchanged. | Standalone tests, a Go 1.27.3 binary build, and actual CLI install/describe against a temporary pinned bundle catalog passed. Real Terraform lifecycle tests require the opt-in pinned CLI fixture. |
| Pulumi | Uses the same typed `iac.New` contract in a separate Go module. | Optional build; absent from the default Git catalog. `describe` and execution require an administrator-installed pinned native bundle catalog. | Separate-module tests, a Go 1.27.3 binary build, and actual CLI install/describe against a temporary pinned bundle catalog passed. The binary is 35,257,874 bytes, below Hostlier's 128 MiB package limit. Real Pulumi lifecycle tests require opt-in native fixtures. |

The active `hostlier-packages` root module's post-update `govulncheck` scan had no findings. Its Pulumi module retained only module-level `GO-2026-5932` for the unused `golang.org/x/crypto/openpgp` package, with no reachable function or imported package finding. The standalone package repository's root suite, both Pulumi modules, and the generated Collector suite passed under Go 1.27.3. Hostlier's cross-repository package-runner test passed, as did the Collector Linux ARM64 cross-build and the targeted provider quality check.

One Hostlier full-suite attempt timed out in two controller tests while concurrent builds were running; both passed when rerun without competing builds. A second full-suite attempt compiled an untracked cloud SDK file while it was being edited and saw missing symbols; that package passed on a targeted rerun after the file settled. The repository-wide `make quality` gate still reports unrelated pre-existing complexity and comment findings outside the provider package.

A final full-suite rerun in the restricted workspace could not complete: the temporary Go build cache exhausted the remaining disk space, and the sandbox denied localhost listeners used by integration tests. The temporary cache from that rerun was removed. This does not change the focused passing results above, but it leaves the full Hostlier suite without a clean end-to-end result in this workspace.

Previously published Aiven and Terraform release assets are not replaced by these local source changes. The four Harnest catalog binaries still use Go 1.27.1: the public Harnest source at commit `ad7a9da59e6feceafa841de9decbd9f04139ad5c` has an older `describe` contract than the current catalog binaries. Its catalog entries were preserved rather than regressed. Rebuilding those four artifacts requires the matching newer Harnest source. No cloud release was published or remote server changed.
