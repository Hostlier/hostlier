# Hostlier guides

Start with setup, then open the guide for what you want to do next.

In the terminal, use `hostlier --help` for the command index, `hostlier app --help` for application actions, and `hostlier app deploy --help` for deployment options. Use `hostlier server --help` for server management and `hostlier access --help` for access and approvals. Existing direct commands such as `hostlier deploy` remain supported. Full offline guides and configuration examples are available with `hostlier skills show COMMAND`.
